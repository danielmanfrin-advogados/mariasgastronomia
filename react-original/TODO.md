# Entregas

## Identidade própria da marca
- [x] O site usa o nome “Maria's Gastronomia Moderna” e um logotipo original, diferente da referência.
- [x] A identidade visual é consistente na navegação, hero, cards, carrinho e rodapé.

## Página inicial e descoberta
- [x] A página inicial apresenta destaques gastronômicos, categorias, produtos em evidência e chamadas para compra.
- [x] O catálogo é organizado por categorias e apresenta fotos, nomes, descrições e preços correspondentes ao conteúdo de referência solicitado.
- [x] Busca e filtros ajudam a encontrar produtos por categoria, faixa de preço ou termo.

## Compra
- [x] Cada produto possui ação clara de adicionar ao carrinho.
- [x] O carrinho permite editar quantidades, remover itens e visualizar resumo do pedido.
- [x] O checkout demonstrativo apresenta dados do cliente, entrega e pagamento de forma clara.

## Responsividade
- [x] O layout funciona em celulares, tablets e desktops.
